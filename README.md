# SWYNEX-Task3-Interactive-Dashboard
🏥 Hospital Management Analytics Dashboard

📌 Project Overview

This project focuses on analyzing hospital data using Microsoft Power BI to create an interactive Hospital Management Analytics Dashboard. It provides insights into patient demographics, hospital departments, admission types, and billing information through visual reports.

🎯 Project Objectives

- Analyze total patient records and average patient age.
- Understand patient distribution by gender and blood type.
- Compare patient counts across hospital departments.
- Analyze patients by admission type and hospital.
- Provide interactive filters for hospital and department analysis.

📊 Dashboard Highlights

- Total Patients: 10K
- Average Patient Age: 51.57
- Total Billing Amount: 270.58M
- Patients by Department
- Patients by Gender
- Patients by Blood Type
- Patients by Admission Type
- Patients by Hospital
- Interactive hospital and department slicers

🛠️ Tools & Technologies

- Microsoft Power BI
- DAX
- Data Modeling
- Data Visualization
- Data Analysis

💡 Key Learning Outcomes

- Creating interactive dashboards in Power BI.
- Designing KPI cards and charts.
- Using slicers to filter and explore data.
- Presenting data through meaningful visualizations.
